# Overview

**موجَک | Motiva** — پلتفرم هوشمند مدیریت ناوگان ربات‌های خودران (AMR) و اتوماسیون لجستیک داخلی کارخانه/انبار. تگ‌لاین: «هوش پشت هر حرکت».

## وضعیت فعلی پروژه
این ریپو در مرحله **پیش از کدنویسی محصول** است — هنوز backend/frontend واقعی نوشته نشده. محتوای فعلی صرفاً مواد marketing/brand/fundraising است:
- `brand/` — هویت بصری (لوگو SVG، پالت رنگ، تایپوگرافی، لحن برند) → [[concepts/brand-identity]]
- `landing/index.html` — لندینگ استاتیک (Tailwind CDN, یک فایل)
- `pitch/motiva-pitch-deck.html` — سورس پیچ‌دک قابل ویرایش (۹ اسلاید HTML/CSS)
- `outputs/` — خروجی نهایی پیچ‌دک (PDF + PPTX)
- `README.md` — لندینگ‌پیج ریپوی گیت‌هاب
- `docs/wiki/` — همین ویکی (منبع اصلی حقیقت؛ نسخه خواندنی هم در GitHub Wiki)

نقشه‌راه توسعه فنی به‌صورت ۱۲ Issue در گیت‌هاب (`massoudsh/motiva`) با ۳ milestone فاز ثبت شده → [[concepts/dev-roadmap]]

## چهار ستون هوشمندی محصول (طبق پیچ‌دک)
۱. ناوبری خودران پویا — مسیر بدون خط ثابت، تشخیص لحظه‌ای مانع
۲. بهینه‌سازی جریان مواد — گلوگاه‌یابی و بازتخصیص مأموریت
۳. مدیریت ناوگان — هماهنگی هم‌زمان صدها ربات، زمان‌بندی شارژ
۴. یکپارچگی ERP/WMS/MES — اتصال به سیستم‌های سازمانی کارخانه

معماری: `🤖 ناوگان AMR → 🧠 هسته هوشمند موجَک → 🏭 ERP/WMS/MES`

## مسیر رشد محصول (۳ فاز)
۱. Design Partner MVP → ۲. مقیاس‌گیری ناوگان → ۳. پلتفرم جامع لجستیک + Digital Twin

## بازار و مدل کسب‌وکار
FMCG/خودروسازی، فولاد/معدن، دارو، لجستیک/تجارت الکترونیک. مدل: Enterprise (سخت‌افزار + SaaS)، درآمد تکرارشونده از لایه نرم‌افزار.

## نکته مهم برای ادامه کار
وقتی کدنویسی واقعی محصول (backend/frontend/robot-control) شروع شود، این wiki باید entityهای واقعی (سرویس‌ها، مدل داده، API) اضافه کند — فعلاً چون کدی نیست، صفحات فقط ساختار مارکتینگ/برند/roadmap را پوشش می‌دهند.
